Latest

3.6: fixes from a full code review

Index and search reliability, plus two fixes to the controls row.

v3.6.27 October 2026 · 19:20
  • Fix: with the console open and the window not full screen, Search dropped underneath the toggles. The search panel now keeps at least the width its controls row needs and the console takes the rest.
  • Below 1220px the console stacks under the search panel instead.
  • SubSleuth.exe rebuilt from this version.
v3.6.17 October 2026 · 17:22
  • Fix: the Time column overlapped the subtitle text in Departure Mono. It is wider now and fits in every font.
  • Fix: the controls row compacted far more than needed. It now compacts in two steps by panel width, and stays on one line in all six fonts.
v3.67 October 2026 · 17:04
  • Export CSV works: pywebview blocked every download, so no file was saved. It now opens a Save As dialog.
  • Searching an offline or missing folder no longer deletes that location's index or adds a junk entry to Indexed Locations.
  • A folder and its subfolders no longer take indexed files from each other, and searching a subfolder no longer includes sibling folders whose names start the same way.
  • Subtitles saved as Windows-1252 keep their accented letters, and UTF-16 subtitle files are now searchable.
  • One unreadable subtitle file no longer makes every search of its folder fail. It is skipped, logged in the console and retried on the next sync.
  • Videos whose subtitle name differs only in capitals are no longer counted as missing subtitles.
  • With Group by File on, same-named files from different folders get separate groups, labelled with their folder.
  • A search and a Re-Index no longer update the database at the same time.
  • SubSleuth.exe rebuilt from this version.
