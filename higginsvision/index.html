Overview

What it does

Higgins Vision is a single web page that plays a video you already have on your computer next to its YouTube live chat replay. As the video plays, the chat messages that were sent at that moment appear, just as they did during the stream. It is meant for reading the chat of the archived streams alongside the video.

Synced chat

Messages appear as the video plays. Seeking forward or back re-syncs the chat to the new position.

Click to jump

Click any chat message to move the video to the moment it was sent.

Search and auto-scroll

A search box filters the chat, and an auto-scroll toggle keeps the newest message in view.

Subtitles

Choose an .srt or .vtt file, or drop it on the page, and turn the subtitles on and off with the Subtitles button.

Super Chats and memberships

Paid messages and memberships are highlighted so they are easy to spot.

Pictures and emoji

Profile pictures and emoji are shown. Standard emoji display as characters and channel emoji as their pictures.

Fullscreen Chat

Puts the video and the chat together on one screen. Press F or Escape to leave it.

YouTube links

Paste a YouTube link under the video to play it in YouTube's own player, with the chat from your file synced to it. The Info button explains the limits, such as embedding and internet access. YouTube links play on the live site, which is hosted on GitHub Pages.

Download Chat JSONs

A button next to Choose chat JSON opens the archive's chat folder, so the matching live_chat.json is easy to find.

Using it

Getting started

Open the live player at higginsvision.francishigginsarchive.biz, which is hosted on GitHub Pages so YouTube links work there. You can also open index.html from your computer for local files only. Then load the two files either with the buttons or by dragging them onto the page.

1. Choose the video

Click Choose video and pick an MP4, WebM or any other file your browser can play, or paste a YouTube link under the video.

2. Choose the chat

Click Choose chat JSON and pick the matching live_chat.json, as exported by yt-dlp. Download Chat JSONs next to it opens the chat folder. You can download the chats for the streams from the Mainframe stream chats folder.

3. Play

Start the video. Click a chat message at any time to seek to it.

Good to know

Limits and notes

The chat file has to match the part of the stream you are watching. Profile pictures and channel emoji are loaded from YouTube's image servers, so they need an internet connection. If they cannot load, the chat still works and shows the viewer's first letter, or the emoji's :shortcut: text, instead. Large streams can take a short while to load, and the status line says so. An empty chat box tells you why it is empty.

Credits

Sources

The idea of a video with a synced chat panel comes from the Ragtag Archive player, but no code from that project is used. The chat format is the live_chat.json written by yt-dlp for YouTube live chat replays. The design follows the Mainframe design system, the author's own spec for dense desktop tools. Geist and Source Code Pro are embedded in the player (both SIL Open Font License 1.1).
